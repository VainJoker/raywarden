This is a Bitwarden compatible server running on Cloudflare Workers.
You can connect to this server using the official Bitwarden clients.

Demo limitations
This page only supports V1 accounts using PBKDF2 and type 2 user keys. For Argon2, V2, passkeys, or email two-step login, use an official Bitwarden client.
All requests go to this site. Credentials are kept only in this page’s memory and cleared on refresh. If TOTP is enabled, enter your current code here when logging in again.
About changing your master password
When changing a master password in Bitwarden/Vaultwarden on the web, plaintext passwords are used only for calculations in the browser. The server receives only the derived hash and the newly protected master key.
Export a backup before making changes to avoid losing access to encrypted data if something goes wrong.
